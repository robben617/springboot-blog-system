四、设计规范与约定

  • 主键：所有表主键 id 均为 BIGINT 数据库自增（MyBatis-Plus IdType.AUTO）。
  • 逻辑删除：user / article / comment 表含 deleted 字段（0-未删，1-已删），由 MyBatis-Plus @TableLogic 自动处理，不物理删除。
  • 时间字段：create_time / update_time 由 MyMetaObjectHandler 自动填充，无需手动赋值。
  • 字符集：全部表使用 utf8mb4 / utf8mb4_unicode_ci，支持中文与表情。
  • 索引：article 上对 user_id / category_id / status 建索引；comment 上对 article_id 建索引，提升联表与列表查询性能。
  • 密码安全：user 表 password 存 MD5(盐+明文)，salt 随机生成，不使用明文。
  • 多对多：文章与标签通过中间表 article_tag 实现（复合主键）。

五、相对原 E-R 图的修正清单

  • 移除论坛概念：版块表、帖子表、评价表、版主角色、发帖审核流（审核/通过/拒绝）。
  • 保留/沿用博客概念：用户、分类、标签、文章、评论、公告、友情链接。
  • 修正评论模型：新增 comment.parent_id，支持评论回复（楼中楼）。
  • 角色统一为两类：普通用户(0) / 管理员(1)，与代码 Constants 一致。
