# 公告友链文件上传模块接口文档

> 覆盖范围：公告（Announcement）、友情链接（FriendLink）、文件上传（文章封面，File）。
> 数据库表：`announcement`、`friend_link`；上传文件落盘至 `file.upload-path` 配置目录。

## 一、全局约定

### 基础信息

| 项目 | 值 |
|------|------|
| Base URL | `http://localhost:9090` |
| 协议 | HTTP/JSON |
| 认证方式 | Session Cookie（登录后自动携带 JSESSIONID） |
| Session 超时 | 30 分钟 |

### 路径约定

| 前缀 | 说明 |
|------|------|
| `/announcements`、`/friend-links` | 公开只读接口，游客可访问（`WebMvcConfig` 放行） |
| `/admin/announcement`、`/admin/friend-link` | 写操作，**需管理员**（`AdminInterceptor` 拦截） |
| `/article/cover` | 封面上传，**需登录**（`LoginInterceptor` 拦截，游客不可用） |

### 统一返回格式

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 状态码，200 表示成功 |
| msg | String | 提示信息 |
| data | T | 业务数据（不同接口类型不同） |

> 注意：`LoginInterceptor` / `AdminInterceptor` 拦截时返回**真实 HTTP 状态码**（401/403）；
> 业务异常（如参数校验失败、资源不存在）由 `GlobalExceptionHandler` 统一处理，
> HTTP 状态为 200、错误信息在 `body.code` / `body.msg` 中，与文章模块约定一致。

### 统一状态码

| code | 说明 |
|------|------|
| 200 | 成功 |
| 400 | 请求参数有误（标题/名称/地址为空或超长、URL 非 http/https 等） |
| 401 | 未登录（HTTP 层直接返回，body 为空） |
| 403 | 无权限（非管理员调用 /admin/**，HTTP 层直接返回）或账号被禁用登录 |
| 404 | 公告 / 友链不存在 |
| 413 | 上传文件超过 5MB 限制 |
| 500 | 服务器内部错误（含上传了非法格式文件等） |

## 二、公告接口

### 1. 公告列表（公开）

```
GET /announcements
```

**响应示例**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": [
    {
      "id": 3,
      "title": "社区评论规范",
      "content": "请大家文明发言、理性讨论……",
      "createTime": "2026-09-12 12:00:00"
    }
  ]
}
```

排序规则：`create_time` 倒序、`id` 倒序（最新公告在最前）。

### 2. 最新公告（公开，首页展示）

```
GET /announcements/latest?limit=1
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| limit | Integer | 否 | 条数，默认 1，最大 50，非法值按默认处理 |

**响应示例**（`data` 为数组，结构同上）

### 3. 新增公告（管理员）

```
POST /admin/announcement
Content-Type: application/json
```

| 参数 | 类型 | 必填 | 校验 |
|------|------|------|------|
| title | String | 是 | 非空，去除首尾空格后 ≤ 200 字符 |
| content | String | 是 | 非空 |

**请求示例**

```json
{ "title": "系统升级维护公告", "content": "本周六 00:00-02:00 停机维护。" }
```

**响应示例**

```json
{
  "code": 200,
  "msg": "新增公告成功",
  "data": { "id": 4, "title": "系统升级维护公告", "content": "本周六 00:00-02:00 停机维护。", "createTime": "2026-10-17 22:40:00" }
}
```

### 4. 修改公告（管理员）

```
PUT /admin/announcement/{id}
Content-Type: application/json
```

请求/响应同新增；公告不存在时返回 `code=404, msg=公告不存在`。

### 5. 删除公告（管理员）

```
DELETE /admin/announcement/{id}
```

**响应示例**：`{"code":200,"msg":"删除公告成功","data":null}`；不存在时 `code=404`。

## 三、友链接口

### 1. 友链列表（公开）

```
GET /friend-links
```

**响应示例**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": [
    { "id": 1, "name": "Spring 官方", "url": "https://spring.io", "sort": 1, "createTime": "2026-09-01 08:00:00" }
  ]
}
```

排序规则：`sort` 升序、`id` 升序。

### 2. 新增友链（管理员）

```
POST /admin/friend-link
Content-Type: application/json
```

| 参数 | 类型 | 必填 | 校验 |
|------|------|------|------|
| name | String | 是 | 非空，≤ 50 字符 |
| url | String | 是 | 非空，≤ 255 字符，必须以 `http://` 或 `https://` 开头 |
| sort | Integer | 否 | 不传默认 0，值越小越靠前 |

**请求示例**

```json
{ "name": "开源中国", "url": "https://www.oschina.net", "sort": 4 }
```

**响应示例**：`{"code":200,"msg":"新增友链成功","data":{"id":5,"name":"开源中国","url":"https://www.oschina.net","sort":4,"createTime":"…"}}`

### 3. 修改友链（管理员）

```
PUT /admin/friend-link/{id}
```

请求/响应同新增（`sort` 不传则保持原值）；不存在时 `code=404, msg=友链不存在`。

### 4. 删除友链（管理员）

```
DELETE /admin/friend-link/{id}
```

**响应示例**：`{"code":200,"msg":"删除友链成功","data":null}`。

## 四、文件上传接口（文章封面）

### 1. 上传文章封面（需登录）

```
POST /article/cover
Content-Type: multipart/form-data
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | MultipartFile | 是 | 图片文件，仅支持 jpg / jpeg / png / gif / webp，单个 ≤ 5MB（`spring.servlet.multipart.max-file-size=5MB`） |

**响应示例**

```json
{
  "code": 200,
  "msg": "封面上传成功",
  "data": "/upload/2026/10/17/9f86d081884c7d65.png"
}
```

- 返回的 `data` 为可直接访问的相对 URL（`/upload/**` 已在 `WebMvcConfig` 放行），可直接回填到文章的 `cover` 字段；
- 落盘规则：`file.upload-path` 目录下按 `yyyy/MM/dd/` 分日期目录存储，文件名使用 UUID 重命名（防覆盖、防路径注入）；
- 同类接口：头像上传 `POST /user/avatar`（用户模块，已实现），本文档不重复。

### 2. 错误响应

| 场景 | 返回 |
|------|------|
| 未登录 | HTTP 401 |
| 非图片格式（如 txt） | `{"code":500,"msg":"不支持的文件类型，仅支持 jpg/jpeg/png/gif/webp","success":false}` |
| 文件 > 5MB | `{"code":413,"msg":"上传文件过大，请压缩后重试","success":false}` |
| 文件为空 | `{"code":400,"msg":"请选择要上传的文件","success":false}` |

## 五、权限矩阵

| 接口 | 游客 | 普通用户 | 管理员 |
|------|:----:|:--------:|:------:|
| GET /announcements、/announcements/latest | ✅ | ✅ | ✅ |
| GET /friend-links | ✅ | ✅ | ✅ |
| POST/PUT/DELETE /admin/announcement/** | ❌ 401 | ❌ 403 | ✅ |
| POST/PUT/DELETE /admin/friend-link | ❌ 401 | ❌ 403 | ✅ |
| POST /article/cover | ❌ 401 | ✅ | ✅ |
