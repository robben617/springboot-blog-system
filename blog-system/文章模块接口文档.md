# 文章模块接口文档

## 一、全局约定

### 基础信息

| 项目 | 值 |
|------|------|
| Base URL | `http://localhost:9090` |
| 协议 | HTTP/JSON |
| 认证方式 | Session Cookie（登录后由浏览器自动携带 JSESSIONID） |
| Session 超时 | 30 分钟 |

### 路径约定

| 前缀 | 说明 |
|------|------|
| `/articles`、`/articles/{id}` | 公开只读接口，游客可访问 |
| `/article/**` | 写操作 / 「我的文章」，**需登录**（由 `LoginInterceptor` 拦截） |

### 统一返回格式

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 状态码，200 表示成功 |
| msg | String | 提示信息 |
| data | T | 业务数据（泛型，不同接口类型不同） |

### 统一状态码

| code | 说明 |
|------|------|
| 200 | 成功 |
| 400 | 请求参数有误（缺少必填参数、字段超长、状态值非法等） |
| 401 | 未登录（需登录的接口未携带有效 Session） |
| 403 | 无权限（非作者本人且非管理员） |
| 404 | 资源不存在（文章/分类/标签不存在，或草稿对非可见者） |
| 405 | 请求方法不支持 |
| 500 | 服务器内部错误 |

### 文章状态

| 值 | 含义 | 说明 |
|------|------|------|
| 0 | 草稿 | 仅作者本人或管理员可见，其他人访问返回 404 |
| 1 | 已发布 | 所有人可见，浏览量会被计入 |

### 用户角色

| 值 | 含义 |
|------|------|
| 0 | 普通用户 |
| 1 | 管理员（可操作所有文章） |

### 分页参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|------|------|
| pageNum | Long | 1 | 当前页码，从 1 开始 |
| pageSize | Long | 10 | 每页大小 |

### 分页返回结构

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "pageNum": 1,
    "pageSize": 10,
    "total": 100,
    "pages": 10,
    "list": []
  }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| pageNum | Long | 当前页码 |
| pageSize | Long | 每页大小 |
| total | Long | 总记录数 |
| pages | Long | 总页数 |
| list | Array | 数据列表（元素类型见各接口） |

## 二、数据模型

### ArticleDTO（请求体）

| 字段 | 类型 | 必填 | 默认值 | 长度限制 | 说明 |
|------|------|------|------|------|------|
| title | String | ✅ | — | ≤ 200 | 文章标题，会自动 trim 前后空格 |
| content | String | ✅ | — | — | 文章正文，Markdown 格式 |
| categoryId | Long | ❌ | null | — | 分类 ID，传了则校验分类必须存在 |
| cover | String | ❌ | null | ≤ 255 | 封面图 URL，空白串会转为 null |
| summary | String | ❌ | null | ≤ 500 | 文章摘要，空白串会转为 null |
| tagIds | Long[] | ❌ | — | — | 标签 ID 列表 |
| status | Integer | ❌ | 新增: 0 / 修改: 保持原状态 | — | 0-草稿 / 1-已发布；非法值返回 400 |

> **tagIds 特殊说明**：修改文章时 `tagIds = null` 表示**不改动**标签关联；传空数组 `[]` 表示**清空**所有标签。

### Article（写操作返回）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 文章 ID（主键自增） |
| userId | Long | 作者 ID |
| categoryId | Long | 分类 ID，可空 |
| title | String | 标题 |
| cover | String | 封面图 URL |
| summary | String | 摘要 |
| content | String | 正文（Markdown） |
| viewCount | Integer | 浏览量 |
| status | Integer | 0-草稿 / 1-已发布 |
| deleted | Integer | 逻辑删除标记，0-未删除 / 1-已删除 |
| createTime | String | 创建时间，格式 `yyyy-MM-dd HH:mm:ss` |
| updateTime | String | 更新时间，格式 `yyyy-MM-dd HH:mm:ss` |

## 三、接口列表

### 3.1 公开接口（游客可访问）

#### 1. 文章分页列表 / 搜索

**请求**

```
GET /articles
```

**Query 参数**

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|------|------|
| pageNum | Long | ❌ | 1 | 当前页码 |
| pageSize | Long | ❌ | 10 | 每页大小 |
| keyword | String | ❌ | — | 搜索关键词；为空时返回全量已发布文章，非空时按标题/摘要模糊搜索 |

**成功响应**

`data.list` 元素类型为 `ArticleBriefVO`：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 文章 ID |
| title | String | 标题 |
| summary | String | 摘要 |
| cover | String | 封面图 URL |
| viewCount | Integer | 浏览量 |
| createTime | String | 发布时间 |
| authorId | Long | 作者 ID |
| authorNickname | String | 作者昵称 |

**响应示例**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "pageNum": 1,
    "pageSize": 10,
    "total": 42,
    "pages": 5,
    "list": [
      {
        "id": 101,
        "title": "Spring Boot 入门指南",
        "summary": "本文介绍 Spring Boot 的核心概念...",
        "cover": "https://example.com/cover1.jpg",
        "viewCount": 328,
        "createTime": "2026-10-15 14:20:00",
        "authorId": 5,
        "authorNickname": "张三"
      }
    ]
  }
}
```

**业务规则**
- 仅返回状态为已发布（status = 1）的文章
- 已逻辑删除的文章不返回
- 按 `createTime` 倒序排列

#### 2. 文章详情

**请求**

```
GET /articles/{id}
```

**路径参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| id | Long | 文章 ID |

**成功响应**

`data` 类型为 `ArticleDetailVO`：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 文章 ID |
| title | String | 标题 |
| content | String | 正文（Markdown） |
| cover | String | 封面图 URL |
| summary | String | 摘要 |
| viewCount | Integer | 浏览量（接口调用后已自增 +1） |
| status | Integer | 0-草稿 / 1-已发布 |
| categoryId | Long | 分类 ID |
| categoryName | String | 分类名称 |
| authorId | Long | 作者 ID |
| authorNickname | String | 作者昵称 |
| authorAvatar | String | 作者头像 URL |
| tags | Tag[] | 关联标签列表，无标签时返回空数组 `[]` |
| createTime | String | 创建时间 |
| updateTime | String | 更新时间 |

**Tag 结构**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 标签 ID |
| name | String | 标签名称 |
| ... | — | 其他实体字段 |

**响应示例**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "id": 101,
    "title": "Spring Boot 入门指南",
    "content": "# Spring Boot\n\n正文 Markdown 内容...",
    "cover": "https://example.com/cover1.jpg",
    "summary": "本文介绍 Spring Boot 的核心概念...",
    "viewCount": 329,
    "status": 1,
    "categoryId": 3,
    "categoryName": "后端开发",
    "authorId": 5,
    "authorNickname": "张三",
    "authorAvatar": "https://example.com/avatar5.jpg",
    "tags": [
      { "id": 1, "name": "Java" },
      { "id": 4, "name": "Spring" }
    ],
    "createTime": "2026-10-15 14:20:00",
    "updateTime": "2026-10-15 15:30:00"
  }
}
```

**错误响应**

| code | msg | 场景 |
|------|------|------|
| 400 | 文章ID不能为空 | `id` 为空 |
| 404 | 文章不存在或已删除 | 文章不存在、已删除，或为草稿且当前用户既非作者也非管理员 |

**业务规则**
- **浏览量自增**：每次调用接口，`viewCount` 自动 +1（仅对已发布文章）
- **草稿可见性**：草稿仅作者本人或管理员可查看，其他人统一返回 404（不暴露草稿存在性）
- 接口为公开接口，游客也可访问；若用户已登录，后台会从 Session 读取登录信息用于草稿可见性判定

#### 4. 新建文章

**请求**

```
POST /article
Content-Type: application/json
```

**请求体**

`ArticleDTO`（见数据模型）

```json
{
  "title": "Spring Boot 入门指南",
  "content": "# Spring Boot\n\n这里是 Markdown 正文...",
  "categoryId": 3,
  "cover": "https://example.com/cover.jpg",
  "summary": "本文介绍 Spring Boot 的核心概念和快速上手方法。",
  "tagIds": [1, 4],
  "status": 1
}
```

**最简请求体（存草稿）**

```json
{
  "title": "草稿标题",
  "content": "# 草稿正文"
}
```

**成功响应**

`data` 类型为 `Article`（完整实体）

```json
{
  "code": 200,
  "msg": "文章保存成功",
  "data": {
    "id": 104,
    "userId": 5,
    "categoryId": 3,
    "title": "Spring Boot 入门指南",
    "cover": "https://example.com/cover.jpg",
    "summary": "本文介绍 Spring Boot 的核心概念和快速上手方法。",
    "content": "# Spring Boot\n\n这里是 Markdown 正文...",
    "viewCount": 0,
    "status": 1,
    "deleted": 0,
    "createTime": "2026-10-16 10:00:00",
    "updateTime": "2026-10-16 10:00:00"
  }
}
```

**错误响应**

| code | msg | 场景 |
|------|------|------|
| 401 | 未登录，请先登录 | 未携带有效 Session |
| 400 | 请求参数不能为空 | 请求体为 null |
| 400 | 文章标题不能为空 | title 为空或全为空白 |
| 400 | 文章标题不能超过 200 个字符 | title 超长 |
| 400 | 文章内容不能为空 | content 为空或全为空白 |
| 400 | 文章摘要不能超过 500 个字符 | summary 超长 |
| 400 | 封面图URL不能超过 255 个字符 | cover 超长 |
| 400 | 状态只能是 0（草稿）或 1（发布） | status 传了非法值 |
| 404 | 分类不存在 | categoryId 对应的分类不存在 |
| 404 | 部分标签不存在，请检查后重试 | tagIds 中存在不存在的标签 ID |

**业务规则**
- `status` 不传时默认存为草稿（0），避免误操作直接对外公开
- 空白的 `cover` / `summary` 会自动转为 null，不会写入无意义的空串
- 标签 ID 会自动去重（使用 `LinkedHashSet`）

#### 5. 修改文章

**请求**

```
PUT /article/{id}
Content-Type: application/json
```

**路径参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| id | Long | 要修改的文章 ID |

**请求体**

`ArticleDTO`（见数据模型）

```json
{
  "title": "更新后的标题",
  "content": "# 更新后的正文\n\n更多内容...",
  "categoryId": 2,
  "summary": "更新后的摘要",
  "tagIds": [2, 5, 7],
  "status": 1
}
```

**成功响应**

`data` 类型为 `Article`（更新后的完整实体）

```json
{
  "code": 200,
  "msg": "文章修改成功",
  "data": {
    "id": 104,
    "userId": 5,
    "categoryId": 2,
    "title": "更新后的标题",
    "cover": "https://example.com/new-cover.jpg",
    "summary": "更新后的摘要",
    "content": "# 更新后的正文\n\n更多内容...",
    "viewCount": 42,
    "status": 1,
    "deleted": 0,
    "createTime": "2026-10-16 10:00:00",
    "updateTime": "2026-10-16 11:00:00"
  }
}
```

**错误响应**

| code | msg | 场景 |
|------|------|------|
| 401 | 未登录，请先登录 | 未携带有效 Session |
| 403 | 无权限操作该文章（仅作者本人或管理员可操作） | 当前用户既非文章作者也非管理员 |
| 404 | 文章不存在或已删除 | 文章不存在或已被删除 |
| 400 | 请求参数不能为空 | 请求体为 null |
| 400 | 文章标题不能为空 | title 为空或全为空白 |
| 400 | 文章内容不能为空 | content 为空或全为空白 |
| 400 | 状态只能是 0（草稿）或 1（发布） | status 传了非法值 |
| 404 | 分类不存在 | categoryId 对应的分类不存在 |
| 404 | 部分标签不存在，请检查后重试 | tagIds 中存在不存在的标签 ID |

**业务规则**
- **权限**：仅文章作者本人或管理员可修改
- **status 不传**：保持原有状态不变
- **tagIds = null**：不改动标签关联（原文案保留）
- **tagIds = []**（空数组）：清空所有标签关联
- 每次修改后 `updateTime` 会自动更新

#### 6. 删除文章

**请求**

```
DELETE /article/{id}
```

**路径参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| id | Long | 要删除的文章 ID |

**成功响应**

```json
{
  "code": 200,
  "msg": "删除文章成功",
  "data": null
}
```

**错误响应**

| code | msg | 场景 |
|------|------|------|
| 401 | 未登录，请先登录 | 未携带有效 Session |
| 403 | 无权限操作该文章（仅作者本人或管理员可操作） | 当前用户既非文章作者也非管理员 |
| 404 | 文章不存在或已删除 | 文章不存在或已被删除 |

**业务规则**
- **逻辑删除**：数据库中 `deleted` 字段置为 1，文章数据仍保留但对外不可见
- 同时解除文章与所有标签的关联（中间表 `article_tag` 物理删除）
- **权限**：仅文章作者本人或管理员可删除

#### 7. 发布文章（草稿 → 已发布）

**请求**

```
PUT /article/{id}/publish
```

**路径参数**

| 参数 | 类型 | 说明 |
|------|------|------|
| id | Long | 要发布的文章 ID |

**成功响应**

```json
{
  "code": 200,
  "msg": "文章发布成功",
  "data": null
}
```

**错误响应**

| code | msg | 场景 |
|------|------|------|
| 401 | 未登录，请先登录 | 未携带有效 Session |
| 403 | 无权限操作该文章（仅作者本人或管理员可操作） | 当前用户既非文章作者也非管理员 |
| 404 | 文章不存在或已删除 | 文章不存在或已被删除 |

**业务规则**
- 将 `status` 从 0 改为 1
- 若文章已经是发布状态，返回 400 避免无效操作
- **权限**：仅文章作者本人或管理员可操作


**路径参数**

| 参数 | 类型 | 说明 |
|------|------|------|

**成功响应**

```json
{
  "code": 200,
  "msg": "文章已转为草稿",
  "data": null
}
```

**错误响应**

| code | msg | 场景 |
|------|------|------|
| 401 | 未登录，请先登录 | 未携带有效 Session |
| 403 | 无权限操作该文章（仅作者本人或管理员可操作） | 当前用户既非文章作者也非管理员 |

**业务规则**

- **权限**：仅文章作者本人或管理员可操作

## 四、接口总览

| # | 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|------|
| 1 | GET | `/articles` | 公开 | 文章分页列表 / 关键词搜索 |
| 2 | GET | `/articles/{id}` | 公开 | 文章详情（浏览量 +1） |
| 3 | GET | `/article/my` | 登录 | 我的文章列表（含草稿） |
| 4 | POST | `/article` | 登录 | 新建文章 |
| 5 | PUT | `/article/{id}` | 登录 + 作者/管理员 | 修改文章 |
| 6 | DELETE | `/article/{id}` | 登录 + 作者/管理员 | 删除文章（逻辑删除） |
| 7 | PUT | `/article/{id}/publish` | 登录 + 作者/管理员 | 发布文章 |
| 8 | PUT | `/article/{id}/draft` | 登录 + 作者/管理员 | 转为草稿 |
