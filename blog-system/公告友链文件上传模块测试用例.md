## 三、已知设计约定（非缺陷）

1. **业务异常 HTTP 状态恒为 200**：参数校验失败（400）、资源不存在（404）、账号禁用（403）、文件超限（413）等均通过 `GlobalExceptionHandler` 返回 HTTP 200 + `body.code` 表达；只有拦截器（401/403）返回真实 HTTP 状态码。与文章模块、用户模块约定一致。
2. **封面上传不需要管理员**：登录用户（含普通用户）即可上传，与头像上传口径一致；仅文章的发布/修改等写操作按文章模块规则控制。
3. **上传文件名 UUID 重命名**：防止路径注入与文件覆盖，扩展名白名单 jpg/jpeg/png/gif/webp。
